후킹

후킹(Hooking) 이란 운영체제, 응용 소프트웨어 등의 각종 컴퓨터 프로그램에서 소프트웨어의 구성 요소 간에 발생하는

함수 호출, 메세지, 이벤트 등을 중간에서 바꾸거나 가로채는 명령, 방법, 기술이나 행위를 말한다.

 

※ 간섭된 함수 호출, 이벤트 또는 메세지를 처리하는 코드를 훅(Hook) 이라고 한다.

 

쉽게 말해서, 특정 함소 코드를 가로채서 원하는 행위를 한 다음에 기존의 코드로 돌려주는 것으로

다양한 변조가 가능한 기술이기에 크래커들이 자주 사용해오던 기법이다.

 

후킹의 종류로는 API 후킹, 메세지 후킹, 함수 후킹, 커널 후킹, 라이브러리 후킹 등 다양한 후킹 방식이 존재한다.

Frida

Frida 는 Windows, macOS, Linux, Android, iOS 등

다양한 플랫폼의 네이티브 애플리케이션에 후킹을 수행할 수 있도록 설계된 도구이다.

Python 기반으로 동작하고, 스크립트 작성은 JavaScript, C, Swift 등의 언어를 활용한 API 를 통해 가능하게 되어있다.

 

단순한 함수 후킹 외에도 암호, 복호화 루틴 추적, 실시간 트래픽 스니핑 등의 기능들을 수행할 수 있어

모바일 애플리케이션 보안 테스트에 필수적인 도구 중 하나이다.

 

Frida 설치는 1주차를 참고하기를 바란다.

후기

보통 내가 알고 있는 기법들은 기존의 코드를 변조시키는 기능을 하고 있다.

하지만 후킹은 원하는 행위를 하고 기존의 코드를 돌려주는 점이 매우 인상적이다.
