Kotlin vs Java

앞에서 Kotlin 은 Java 와 유사하다고 했다.

다시 말하면, Java 와 다른 부분도 있다는 것이다.

어떤 부분이 Java 와 다른지 지금부터 소개하겠다.

진입점, 세미콜론

Hello World 를 출력하는 프로그램을 Kotlin 과 Java 로 만들어봤다.

fun main() {
    println("Hello World")
}
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}

차이점은 무엇일까?

먼저 진입점이 다르다.

Java 에서는 프로그램을 실행할 때 public static void main(String[] args) 이라는 메서드를 사용하였다.

그러나 Kotlin 에서는 fun main() 이라는 함수를 사용하였다.

함수와 메서드의 차이는 클래스의 유무 차이이다.

함수는 클래스 내부에 없어서 독립적이고

메서드는 클래스 내부에 있어서 종속적이다.

또한 Kotlin 에서 println() 함수를 보면 마지막에 세미콜론(;) 이 존재하지 않는다.

이 또한 Java 와 다른 부분이다.

Java 는 세미콜론이 필수적으로 사용된다.

변수 선언 방식

Kotlin 은 Java 와 다르게 var, val 로 변수 선언을 시작하고 변수명 뒤에 타입을 지정한다.

var 는 값을 변경할 수 있는 변수, val 은 값을 변경할 수 없는 변수를 선언할 때 사용된다.

fun main() {
	var num1: Int = 222
    num1 = 200
    
    val num2: Int = 333
    num2 = 300
    
    println(num1)
    println(num2)
}

Nullable

Java 는 모든 변수를 기본적으로 Nullable 로 정의한다.

그리고 null-check 구문을 만들어 NPE(Null Pointer Exception) 을 피하려 한다.

※ NPE : null 로 인해 발생하는 Runtime Exception

Kotlin 에서는 null 을 허용하지 않는 Non-Nullable 타입이 존재한다.

그래서 null 을 사용하고 싶다면 변수 타입에 ? 를 붙여 Nullable 타입으로 지정할 수 있다.

이 덕분에 NPE 를 줄일 수 있는 장점이 있다.

fun main() {
    val num1: Int? = null
    println(num1)

    val num2: Int = null
    println(num2)
}

이 프로그램을 실행하면 어떻게 될까?

※ !! 문법

변수 뒤에 !! 을 사용하여 변수가 null 이 아님을 지정하는데 사용한다.

null 에 대한 처리를 하는 것이 아니라

강제로 null 이 아님을 명시할 수 있는 것이라서 권장하지는 않는다.

엘비스 연산자

엘비스 연산자는 null 을 활용한 연산자이다.

?: 로 엘비스 연산자를 사용할 수 있다.

엘비스 연산자는 어떻게 활용할 수 있을까?

예를 들어 특정 변수가 null 인 경우 특정한 값을 반환시킬 수 있다. 

fun main() {
    val num: Int? = null

    print(num ?: "num is Nullable")
}

when() 조건문

Kotlin 에는 Java 의 switch 조건문과 유사한 when 조건문이 있다.

switch 처럼 case 마다 조건을 설정할 수 있다.

fun main() {
	val num: Int = 3
    
    when (num) {
    	1 -> print("Your number is 1.")
        2 -> print("Your number is 2.")
        3 -> print("Your number is 3.")
        else -> print("I can't know your number.")
        }
}

함수 선언

fun main() {
    val Msg1 = fun1(1)
    val Msg2 = fun2(2)

    println(Msg1)
    println(Msg2)
}

fun fun1(a : Int): String {
    return "I am Msg1"
}

fun fun2(a : Int): String = "I am Msg2"

이 프로그램에서 2개의 함수를 선언하였다.

파라미터 타입을 지정하고, 리턴 타입 또한 같은 형식으로 지정하면 된다.

fun2 처럼 함수가 매우 짧은 경우 중괄호를 사용하지 않고 = 를 사용하여 이어적어도 된다.

또한 Kotlin 은 메서드 오버로딩을 지원한다.

함수명이 같아도 파라미터가 다르다면

다른 동작을 할 수 있도록 구현할 수 있다.

fun main() {
    val Msg = fun1(1)
    val Msg2 = fun1(2, 3)

    println(Msg)
    println(Msg2)
}

fun fun1(a : Int): String {
    return "return"
}

fun fun1(a : Int, b : Int): String {
    return  "overloaded function's return"
}

이 프로그램의 경우 fun1 로 함수의 이름은 같지만 파라미터가 다르다.

a 만 사용하는 경우 return 을 반환하고

a, b 를 사용하는 경우 overloaded function's return 을 반환한다.

후기

Kotlin 이 안드로이드 공식 언어로 추가되었지만

단순히 모바일 애플리케이션 개발에만 사용될 언어는 아니라고 생각한다.

Java 와 상호 운용이 가능해서 Java 에서 Kotlin 으로 넘어가는 사람들이 많다.

만약 기존에 Java 를 사용하고 있다면,

Kotlin 도 쉽게 배울 수 있을테니 같이 사용해 보는 것도 좋을 것 같다.
